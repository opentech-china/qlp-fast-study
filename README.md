# qlp-fast-study
learn whut-qlp as fast as possible to save energy and time

#### Our Demo Page : [青梨派快速刷](https://opentech-china.github.io/qlp-fast-study/)

### detail and method

1. Use your **PC** , start your browser and go to the website below: Scan the QR Code to login

   [理工易班大学生数智思政学习平台-理工易班聚合看平台](https://qlp.whut.edu.cn/mp-pc/home)

   ![image1](https://opentech-china.github.io/qlp-fast-study/image1.png)

2. Press **Ctrl+Shift+I** to show debug window

3. Press **Ctrl+R** to reload the page

4. check your **XHR Reqests** and get Your HTTP requets **headers** --> **Authorization** token string

   ![image2](https://opentech-china.github.io/qlp-fast-study/image2.png)

5. Copy your Authorization and Paste it to our demo webpage
